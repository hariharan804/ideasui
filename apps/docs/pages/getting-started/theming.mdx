# Theming

Customize the design system to match your brand with our flexible theming approach.

## CSS Variables

Our components use CSS variables for theming. Override these in your CSS:

```css filename="globals.css"
:root {
  --primary: 220 14% 96%;
  --primary-foreground: 220 9% 46%;
  --secondary: 220 14% 96%;
  --secondary-foreground: 220 9% 46%;
  --accent: 220 14% 96%;
  --accent-foreground: 220 9% 46%;
}

.dark {
  --primary: 220 14% 4%;
  --primary-foreground: 220 9% 98%;
  --secondary: 220 14% 4%;
  --secondary-foreground: 220 9% 98%;
  --accent: 220 14% 4%;
  --accent-foreground: 220 9% 98%;
}
```

## Tailwind Configuration

Extend your Tailwind config with custom colors:

```js filename="tailwind.config.js"
module.exports = {
  theme: {
    extend: {
      colors: {
        primary: {
          50: '#eff6ff',
          500: '#3b82f6',
          900: '#1e3a8a',
        }
      }
    }
  }
}
```

## Component Variants

Use the `className` prop to customize individual components:

```tsx
<Button className="bg-green-500 hover:bg-green-600">
  Custom Button
</Button>
```
