# Installation

Get started with our component library in just a few steps.

## Package Installation

```bash
npm install @your-org/ui
```

## Peer Dependencies

Install the required peer dependencies:

```bash
npm install react react-dom
```

## Tailwind CSS Setup

Our components require Tailwind CSS. Install it if you haven't already:

```bash
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p
```

Update your `tailwind.config.js`:

```js filename="tailwind.config.js"
/** @type {import('tailwindcss').Config} */
module.exports = {
  content: [
    './pages/**/*.{js,ts,jsx,tsx,mdx}',
    './components/**/*.{js,ts,jsx,tsx,mdx}',
    './app/**/*.{js,ts,jsx,tsx,mdx}',
    './node_modules/@your-org/ui/**/*.{js,ts,jsx,tsx}'
  ],
  theme: {
    extend: {}
  },
  plugins: []
}
```

## CSS Import

Add the component styles to your main CSS file:

```css filename="globals.css"
@tailwind base;
@tailwind components;
@tailwind utilities;
```

## First Component

You're ready to use components:

```tsx filename="app/page.tsx"
import { Button } from '@your-org/ui'

export default function Home() {
  return (
    <div className="p-8">
      <Button>Hello World!</Button>
    </div>
  )
}
```
