# Interactive Playground

Explore and test components in real-time with our interactive playground powered by Storybook.

## Live Component Testing

The playground allows you to:
- **Test Components**: Interact with components in isolation
- **Modify Props**: Change component properties in real-time  
- **View Code**: See the generated code for each example
- **Accessibility Testing**: Built-in a11y checks
- **Responsive Testing**: Test across different viewport sizes

### Form Components

## Development Workflow

1. **Component Development**: Create components in `/packages`
2. **Story Creation**: Add stories in `/stories` 
3. **Interactive Testing**: Use Storybook for live testing
4. **Documentation**: Document usage in these docs
5. **Integration**: Test in real applications

## Story Structure

Stories follow this pattern:

```tsx
import type { Meta, StoryObj } from '@storybook/react'
import { Button } from '@your-org/ui'

const meta: Meta<typeof Button> = {
  title: 'Components/Button',
  component: Button,
  parameters: {
    layout: 'centered',
  },
  tags: ['autodocs'],
}

export default meta
type Story = StoryObj<typeof meta>

export const Primary: Story = {
  args: {
    children: 'Button',
    variant: 'default',
  },
}
```
