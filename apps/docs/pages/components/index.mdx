# Components

Explore our comprehensive collection of accessible, customizable React components.

## Form Components

### Button
Interactive button component with multiple variants and sizes.

```tsx
import { Button } from '@your-org/ui'

<Button variant="default">Primary Button</Button>
<Button variant="outline">Outline Button</Button>
<Button variant="ghost">Ghost Button</Button>
```

### Input
Text input component with validation states.

```tsx
import { Input } from '@your-org/ui'

<Input placeholder="Enter your name" />
<Input type="email" placeholder="Email address" />
```

## Layout Components

### Card
Container component for grouping related content.

```tsx
import { Card, CardHeader, CardContent } from '@your-org/ui'

<Card>
  <CardHeader>
    <h3>Card Title</h3>
  </CardHeader>
  <CardContent>
    <p>Card content goes here.</p>
  </CardContent>
</Card>
```

## Navigation Components

### Breadcrumb
Navigation component showing the current page's location.

```tsx
import { Breadcrumb, BreadcrumbItem } from '@your-org/ui'

<Breadcrumb>
  <BreadcrumbItem href="/">Home</BreadcrumbItem>
  <BreadcrumbItem href="/components">Components</BreadcrumbItem>
  <BreadcrumbItem>Button</BreadcrumbItem>
</Breadcrumb>
```
