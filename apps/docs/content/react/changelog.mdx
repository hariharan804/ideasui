## v1.2.0

*2024-12-15*

- **Added**: New `Drawer` component with edge-drag handlers and multi-placement options (left, right, top, bottom).
- **Added**: `Pagination` components supporting responsive dot ranges and dynamic page limits.
- **Fixed**: Modal layout focus trap issues on multi-layered overlay stack trees.
- **Improved**: Button component loading configurations now prevent dynamic text layout shifts.
