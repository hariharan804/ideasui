Welcome to IdeasUI, a modern, accessible, and high-performance component library for React.

## Installation

To start using IdeasUI in your project, install the core package and the theme engine:

```bash
npm install @ideasui/react @ideasui/theme
```

## Quick Start

Import the CSS theme in your root layout and start using components:

```tsx
import '@ideasui/theme/theme.css';
import { Button } from '@ideasui/react';

export default function App() {
  return <Button color="primary">Hello IdeasUI</Button>;
}
```
