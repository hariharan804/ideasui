### Composition & Compound Components

The Button component uses compound components for maximum flexibility:

- `Button.Label` - The text content of the button.
- `Button.Icon` - For adding icons, with a `placement` prop.
- `Button.Spinner` - Customizable loading indicator.
- `Button.Shortcut` - Display keyboard shortcuts.

```tsx
<Button>
  <Button.Icon placement="start"><Search /></Button.Icon>
  <Button.Label>Search</Button.Label>
  <Button.Shortcut>⌘K</Button.Shortcut>
</Button>
```

### Button Group

You can group multiple buttons together using the `Button.Group` component. It automatically shares layout, size, color, and variant across its children, and supports vertical/horizontal stacking.

```tsx
<Button.Group variant="outline" color="primary" isAttached>
  <Button>Feed</Button>
  <Button>Messages</Button>
  <Button>Notifications</Button>
</Button.Group>
```

## Styling

### CSS Classes

The Button component uses granular class names and the BEM methodology for slots:

- `base` - Base button container
- `label` - Text label slot
- `startIcon` - Leading icon slot
- `endIcon` - Trailing icon slot
- `spinner` - Loading spinner slot
- `shortcut` - Keyboard shortcut slot

### Interactive States

The button supports both CSS pseudo-classes and data attributes for flexibility:

- **Hover**: `:hover` or `[data-hovered="true"]`
- **Active/Pressed**: `:active` or `[data-pressed="true"]`
- **Focus**: `:focus-visible` or `[data-focus-visible="true"]`
- **Disabled**: `:disabled` or `[aria-disabled="true"]`
- **Pending**: `[data-pending]` (no pointer events during loading)

## API Reference

### Button Props

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `variant` | `'solid' \| 'outline' \| 'ghost' \| 'soft' \| 'link' \| 'text' \| 'elevated' \| 'glaze'` | `'solid'` | The visual style variant. |
| `color` | `'primary' \| 'secondary' \| 'tertiary' \| 'neutral' \| 'danger' \| 'success' \| 'warning' \| 'info'` | `'primary'` | Semantic color theme. |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | Size of the button. |
| `radius` | `'none' \| 'sm' \| 'md' \| 'lg' \| 'xl' \| 'full'` | `'md'` | The border radius. |
| `isLoading` | `boolean` | `false` | Loading state of the button. |
| `loadingIndicator`| `ReactNode` | - | Custom loading indicator element. |
| `loadingPosition`| `'start' \| 'end' \| 'center'` | `'start'` | Where the loading indicator appears. |
| `isIconOnly` | `boolean` | `false` | Whether the button only contains an icon. |
| `isDisabled` | `boolean` | `false` | Whether the button is disabled. |
| `fullWidth` | `boolean` | `false` | Takes the full width of the container. |
| `disableAnimation`| `boolean` | `false` | Disables press and hover animations. |
| `shortcut` | `ReactNode` | - | Keyboard shortcut to display. |
| `classNames` | `ButtonClassNames` | - | Custom class names for internal slots. |
| `onPress` | `(e: PressEvent) => void` | - | Click/Press handler. |
| `children` | `ReactNode \| (props: ButtonRenderProps) => ReactNode` | - | Content of the button. |

### Button.Group Props

| Prop | Type | Default | Description |
| ---- | ---- | ------- | ----------- |
| `isAttached` | `boolean` | `true` | Joins the buttons without gaps. |
| `isVertical` | `boolean` | `false` | Stacks the buttons vertically. |
| `showDivider` | `boolean` | `true` | Shows dividers between attached buttons. |
| `variant` | `ButtonVariant` | - | Passed down to all child buttons. |
| `color` | `ButtonColor` | - | Passed down to all child buttons. |
| `size` | `ButtonSize` | - | Passed down to all child buttons. |
| `radius` | `ButtonRadius` | - | Passed down to all child buttons. |
| `isDisabled` | `boolean` | `false` | Disables all child buttons. |
| `fullWidth` | `boolean` | `false` | Takes the full width of the container. |
| `disableAnimation`| `boolean` | `false` | Disables animations for all child buttons. |
