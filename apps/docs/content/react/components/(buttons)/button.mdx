## Composition

The Button component uses compound components for maximum flexibility:

- `Button.Label` - The text content of the button.
- `Button.Icon` - For adding icons, with a `placement` prop.
- `Button.Spinner` - Customizable loading indicator.
- `Button.Shortcut` - Display keyboard shortcuts.

```tsx
<Button>
  <Button.Icon placement="start">
    <Search />
  </Button.Icon>
  <Button.Label>Search</Button.Label>
  <Button.Shortcut>⌘K</Button.Shortcut>
</Button>
```

## Standalone CSS

### CSS Classes

The Button component uses granular class names and the BEM methodology for slots:

- `base` - Base button container
- `label` - Text label slot
- `startIcon` - Leading icon slot
- `endIcon` - Trailing icon slot
- `spinner` - Loading spinner slot
- `shortcut` - Keyboard shortcut slot

### Interactive States

The button supports both CSS pseudo-classes and data attributes for flexibility:

- **Hover**: `:hover` or `[data-hovered="true"]`
- **Active/Pressed**: `:active` or `[data-pressed="true"]`
- **Focus**: `:focus-visible` or `[data-focus-visible="true"]`
- **Disabled**: `:disabled` or `[aria-disabled="true"]`
- **Pending**: `[data-pending]` (no pointer events during loading)
