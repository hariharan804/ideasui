### Anatomy

Import the `Button.Group` (or `ButtonGroup`) component and access all parts using dot notation or directly.

```tsx
import { Button } from '@ideasui/react';

export default () => (
  <Button.Group>
    <Button>First</Button>
    <Button>Second</Button>
    <Button>Third</Button>
  </Button.Group>
);
```

> **Button.Group** wraps multiple Button components together, applying consistent styling, spacing, and automatic border radius handling. It uses React Context to pass `size`, `variant`, `color`, and `isDisabled` props to all child buttons automatically without requiring manual separators.

## Styling

### Passing Tailwind CSS classes

```tsx
import { Button } from '@ideasui/react';

function CustomButtonGroup() {
  return (
    <Button.Group className="gap-4 shadow-xl">
      <Button>First</Button>
      <Button>Second</Button>
      <Button>Third</Button>
    </Button.Group>
  );
}
```

### CSS Classes

The Button Group component uses these core data attributes and states for flexibility:

- `[data-slot="button-group"]` - Base button group container
- `[data-attached="true"]` - When buttons are attached seamlessly
- `[data-vertical="true"]` - When buttons are stacked vertically

The Button Group component automatically applies border radius to buttons via CSS adjacent sibling selectors. No manual separator elements are required!

### Notes

- Button Group uses React Context to pass `size`, `variant`, `color`, and `isDisabled` props to all child Button components.
- **Only direct child buttons receive the Button Group props** - Buttons nested inside other components will not inherit the group's props even if they are descendants of the Button.Group.
- Individual Button components can override the group's properties (like `isDisabled={false}`) if explicitly provided.
- The component automatically handles border radiuses between buttons via CSS. No extra separator components are needed.
