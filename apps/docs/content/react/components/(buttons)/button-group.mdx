```tsx
import { ButtonGroup } from '@ideasui/button';
```

## Basic Usage

<Preview name="button-group-basic" />

### Variants

Just like individual buttons, Button Group supports all visual variants, including solid, outline, ghost, soft, link, text, elevated, and surface. Borders and corner radiuses seamlessly integrate between adjacent buttons.

<Preview name="button-group-variants" />

### Sizes

Apply a `size` prop to the group to uniformly scale all buttons inside it (`xs`, `sm`, `md`, `lg`, `xl`).

<Preview name="button-group-sizes" />

### Orientation

Use `isVertical` to stack buttons vertically instead of horizontally. Perfect for sidebars, action panels, and vertical toolbars.

<Preview name="button-group-vertical" />

### With Icons

Combine text and icons inside group items for descriptive actions.

<Preview name="button-group-with-icons" />

### Full Width

Use `fullWidth` when the button group should stretch to fill its container width.

<Preview name="button-group-full-width" />

### Disabled State

Disable all buttons within the group simultaneously by passing `isDisabled` to `ButtonGroup`, or disable specific individual buttons.

<Preview name="button-group-disabled" />

### Dividers

Configure dividers between attached buttons using the `divider` prop (`'full'`, `'middle'`, or `'none'`).

<Preview name="button-group-dividers" />

### Detached Mode

Pass `isAttached={false}` to remove attached borders and clipping, creating a grouped layout with standard spacing gaps.

<Preview name="button-group-detached" />

## Composition

Button Group supports compound component dot-notation (`Button.Group`) to keep component imports clean:

```tsx
import { Button } from '@ideasui/react';

export function ToolbarExample() {
  return (
    <Button.Group size="sm" variant="outline">
      <Button>Cut</Button>
      <Button>Copy</Button>
      <Button>Paste</Button>
    </Button.Group>
  );
}
```

## Standalone CSS

Button Group can also be used in projects that do not use Tailwind CSS.

Install the standalone styles package:

```bash
npm install @ideasui/styles
```

Import base styles and component CSS:

```tsx
import '@ideasui/styles/base.css';
import '@ideasui/styles/components/button.css';
```

### Custom Styling

Pass custom classes to the group container using `className`:

```tsx
<ButtonGroup className="gap-2 shadow-lg">
  <Button>First</Button>
  <Button>Second</Button>
</ButtonGroup>
```

### CSS Attributes & Selectors

The Button Group component uses DOM data attributes to manage structural layout and attached borders via CSS:

- `[data-slot="button-group"]` — Base container selector.
- `[data-attached="true"]` — Active when buttons are attached seamlessly.
- `[data-vertical="true"]` — Active when orientation is vertical.

Adjacent sibling selectors automatically handle border radius clipping between connected buttons without requiring manual divider elements.
