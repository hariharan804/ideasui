## Import

```tsx
import {
  Switch,
  SwitchGroup,
  SwitchGroupLabel,
  SwitchGroupDescription,
  SwitchGroupError,

import { Switch, SwitchGroup } from '@ideasui/switch';
```

## Basic Usage

A standalone `Switch` can be used out of the box with default or controlled selection state:

<Preview name="switch-basic" />

```tsx
<Switch defaultSelected>Enable notifications</Switch>
```

## Variants & Color Schemes

`Switch` supports `solid` (default), `outline`, and `soft` visual style variants, as well as `primary`, `neutral`, `success`, `warning`, and `danger` OKLCH color schemes.

<Preview name="switch-variants" />

```tsx
<Switch variant="solid" defaultSelected>
  Solid
</Switch>
<Switch variant="outline" defaultSelected>
  Outline
</Switch>
<Switch variant="soft" defaultSelected>
  Soft
</Switch>
```

<Preview name="switch-colors" />

```tsx
<Switch color="primary" defaultSelected>
  Primary
</Switch>
<Switch color="neutral" defaultSelected>
  Neutral
</Switch>
<Switch color="success" defaultSelected>
  Success
</Switch>
<Switch color="warning" defaultSelected>
  Warning
</Switch>
<Switch color="danger" defaultSelected>
  Danger
</Switch>
```


## Controlled State

Manage the switch selection using React state (`isSelected` and `onChange`).

<Preview name="switch-controlled" />

```tsx
import { useState } from 'react';
import { Switch } from '@ideasui/react';

export function ControlledExample() {
  const [isSelected, setIsSelected] = useState(true);

  return (
    <div className="flex flex-col gap-3">
      <Switch isSelected={isSelected} onChange={(checked) => setIsSelected(checked)}>
        Subscribe to email updates
      </Switch>
      <p className="text-xs">State: {isSelected ? 'ON' : 'OFF'}</p>
    </div>
  );
}
```

## Switch Group

`SwitchGroup` manages grouped selection states and propagates theme, size, and state props to child switches:

<Preview name="switch-group" />

```tsx
<SwitchGroup defaultValue={['email']}>
  <SwitchGroupLabel>Notification Channels</SwitchGroupLabel>
  <Switch value="email">Email</Switch>
  <Switch value="sms">SMS</Switch>
  <Switch value="push">Push Notifications</Switch>
  <SwitchGroupDescription>Enable at least one channel.</SwitchGroupDescription>
</SwitchGroup>
```

## Custom Icons

Customize the thumb indicator with SVG icons or dynamic render functions using `thumbIcon`, `checkedThumbIcon`, or `uncheckedThumbIcon`:

<Preview name="switch-custom-icons" />

```tsx
<Switch
  color="success"
  size="lg"
  defaultSelected
  thumbIcon={<CheckIcon className="size-3 text-white" />}
>
  Checked Icon
</Switch>

<Switch
  color="neutral"
  size="lg"
  defaultSelected
  thumbIcon={({ isSelected, className }) =>
    isSelected ? (
      <MoonIcon className={`${className} text-yellow-300`} />
    ) : (
      <SunIcon className={`${className} text-amber-500`} />
    )
  }
>
  Dark Mode Toggle
</Switch>
```

## Standalone CSS

`Switch` can also be used in non-Tailwind projects via the pre-compiled `@ideasui/styles` package.

Install the standalone styles package:

```bash
pnpm add @ideasui/styles
```

Import base tokens and the switch component stylesheet:

```tsx
import '@ideasui/styles/base.css';
import '@ideasui/styles/components/switch.css';
```

Or import all component styles in a single bundle:

```tsx
import '@ideasui/styles';
```

### BEM CSS Classes

`Switch` components expose standard BEM class names and granular slot target selectors generated by the `@ideasui/theme` recipe:

- **Block / Root:** `.ideasui-switch` (`root` slot) — Main label wrapper element (`<label>`).
- **Elements (Slots):**
  - `.ideasui-switch__input` (`input` slot) — Hidden native `<input type="checkbox" role="switch">` element.
  - `.ideasui-switch__track` (`track` slot) — Visual track container element.
  - `.ideasui-switch__thumb` (`thumb` slot) — Animated sliding thumb element inside track.
  - `.ideasui-switch__on-label` (`onLabel` slot) — Text inside track when on.
  - `.ideasui-switch__off-label` (`offLabel` slot) — Text inside track when off.
  - `.ideasui-switch__label-text` (`labelText` slot) — Visible label text element.
- **Group Elements:**
  - `.ideasui-switch-group` (`switch-group` slot) — Group container element (`<div>`).
  - `.ideasui-switch-group__label` (`group-label` slot) — Group label element.
  - `.ideasui-switch-group__description` (`group-description` slot) — Helper description paragraph.
  - `.ideasui-switch-group__error` (`group-error` slot) — Validation error alert paragraph.
