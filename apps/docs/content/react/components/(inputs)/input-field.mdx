## Import

Only a single import statement is required for both shorthand usage and compound composition:

```tsx
import { InputField } from '@ideasui/react';
// or from the individual package
import { InputField } from '@ideasui/input-field';
```

## Basic Usage

The `InputField` component can be used out of the box using shorthand props for clean and simple forms.

<Preview name="input-field-basic" />

```tsx
<InputField
  label="Email address"
  placeholder="you@example.com"
  description="We will never share your email address."
  startContent={<Mail className="h-4 w-4" />}
/>
```

## Composition Patterns

`InputField` supports both **Single Component (Shorthand)** and **Compound Composition** using the same single import.

<Preview name="input-field-shorthand" />

### Single Component (Shorthand)

Pass high-level props (`label`, `placeholder`, `description`, `errorMessage`, `startContent`, `endContent`) directly to `<InputField />`.

```tsx
<InputField
  label="Email Address"
  placeholder="you@example.com"
  description="Single component shorthand usage."
  startContent={<Mail className="h-4 w-4" />}
/>
```

### Compound Composition

For custom layout flexibility and element control, use static dot-notation sub-components (`InputField.Label`, `InputField.Input`, `InputField.Description`, `InputField.Error`).

```tsx
<InputField size="md" variant="outline">
  <InputField.Label>Password</InputField.Label>
  <InputField.Input
    type="password"
    placeholder="Enter your password"
    startContent={<Lock className="h-4 w-4" />}
  />
  <InputField.Description>Must be at least 8 characters long.</InputField.Description>
</InputField>
```

## Label Variants

`InputField` supports four distinct label positioning variants:

- **`default`** — Label sits above the input field.
- **`inside-fixed`** — Label sits permanently inside the top of the input surface.
- **`inside-floating`** — Label sits inside as a placeholder and transitions to the top inside position on focus/value.
- **`floating`** — Label starts inside and floats over the top border on focus/value.

<Preview name="input-field-label-variants" />

```tsx
<InputField labelVariant="default" label="Default Label" />
<InputField labelVariant="inside-fixed" label="Inside Fixed Label" />
<InputField labelVariant="inside-floating" label="Inside Floating Label" />
<InputField labelVariant="floating" label="Floating Label" />
```

## Visual Variants

Control visual styling using the `variant` prop:

- **`outline`** — Standard border container (default).
- **`filled`** — Soft filled surface background.
- **`shadow`** — Subtle elevated shadow container.
- **`flushed`** — Minimal underline border.
- **`unstyled`** — Bare input element without border or background styles.

<Preview name="input-field-variants" />

```tsx
<InputField variant="outline" label="Outline" />
<InputField variant="filled" label="Filled" />
<InputField variant="shadow" label="Shadow" />
<InputField variant="flushed" label="Flushed" />
<InputField variant="unstyled" label="Unstyled" />
```

## Sizes

Choose between three size scales: `sm` (small), `md` (medium / default), and `lg` (large).

<Preview name="input-field-sizes" />

```tsx
<InputField size="sm" label="Small" />
<InputField size="md" label="Medium" />
```

## States & Validation

`InputField` handles interactive, read-only, disabled, required, and error states seamlessly across all sub-components and ARIA attributes.

<Preview name="input-field-states" />

```tsx
{
  /* Required Field */
}
<InputField label="Required Field" isRequired />;

{
  /* Disabled State */
}
<InputField label="Disabled Field" isDisabled />;

{
  /* Read-Only State */
}
<InputField label="Read Only Field" isReadOnly defaultValue="read.only@example.com" />;

{
  /* Invalid / Error State */
}
<InputField label="Invalid State" isInvalid errorMessage="Please enter a valid email address." />;
```

## Controlled State

Manage the input value using standard React state (`value` and `onChange`). When `value` changes dynamically, floating labels automatically adjust their position.

<Preview name="input-field-controlled" />

```tsx
import { useState } from 'react';
import { InputField } from '@ideasui/react';

export function ControlledExample() {
  const [value, setValue] = useState('user@example.com');

  return (
    <InputField label="Controlled Input" value={value} onChange={(e) => setValue(e.target.value)} />
  );
}
```

## Input Filtering

Restrict allowed character entry into the input using the `inputFilter` prop without mixing responsibilities with native HTML `type` or virtual keyboard `inputMode`.

- **`numeric`** — Allows only digits (`0-9`). Automatically sets `inputMode="numeric"`.
- **`decimal`** — Allows digits and a single decimal point (`0-9`, `.`). Automatically sets `inputMode="decimal"`.
- **`alpha`** — Allows only alphabetic letters (`A-Z`, `a-z`).
- **`alphanumeric`** — Allows only alphanumeric characters (`A-Z`, `a-z`, `0-9`).

<Preview name="input-field-filter" />

```tsx
{
  /* Numeric Filter */
}
<InputField inputFilter="numeric" label="Numeric Only" placeholder="123456" />;

{
  /* Decimal Filter */
}
<InputField inputFilter="decimal" label="Decimal Amount" placeholder="99.99" />;

{
  /* Alpha Filter */
}
<InputField inputFilter="alpha" label="First Name" placeholder="Hariharan" />;

{
  /* Alphanumeric Filter */
}
<InputField inputFilter="alphanumeric" label="Username" placeholder="Hari123" />;
```

## Input Types

`InputField` supports native HTML input types via the `type` prop (`type="number"`, `type="password"`, `type="search"`, `type="email"`, `type="tel"`, `type="url"`).

- **`number`** — Native numerical input supporting `min`, `max`, and `step` attributes.
- **`password`** — Obfuscated text field for secure password and secret entry.
- **`search`** — Search query input with native clear button support.
- **`email`** — Displays email-optimized keyboard layout on mobile devices.
- **`tel`** — Displays telephone dialer layout on mobile devices.
- **`url`** — Displays URL-optimized keyboard layout on mobile devices.

<Preview name="input-field-types" />

```tsx
{
  /* Number Input */
}
<InputField type="number" label="Quantity" placeholder="10" min={1} max={100} />;

{
  /* Password Input */
}
<InputField type="password" label="Password" placeholder="••••••••" />;

{
  /* Search Input */
}
<InputField type="search" label="Search Query" placeholder="Search..." />;

{
  /* Email Input */
}
<InputField type="email" label="Email Address" placeholder="alex@example.com" />;
```

## Number Input & Buttons

Combine `InputField` with `Button` components to build number steppers, password visibility toggles, or embedded search buttons.

<Preview name="input-field-number-buttons" />

```tsx
{
  /* Number Input with Stepper Controls */
}
<InputField>
  <InputField.Label>Quantity Stepper (Number Input)</InputField.Label>
  <div className="flex items-center gap-2">
    <Button
      variant="outline"
      size="md"
      isIconOnly
      aria-label="Decrease quantity"
      isDisabled={quantity <= 1}
      onClick={decrement}
    >
      <Minus className="h-4 w-4" />
    </Button>

    <InputField.Input
      type="number"
      min={1}
      value={quantity}
      onChange={(e) => setQuantity(Number(e.target.value) || 1)}
      className="w-14"
      inputClassName="text-center"
    />

    <Button
      variant="outline"
      size="md"
      isIconOnly
      aria-label="Increase quantity"
      onClick={increment}
    >
      <Plus className="h-4 w-4" />
    </Button>
  </div>
  <InputField.Description>Interactive number stepper.</InputField.Description>
</InputField>;

{
  /* Password Toggle Button in endContent */
}
<InputField>
  <InputField.Label>Password</InputField.Label>
  <InputField.Input
    type={showPassword ? 'text' : 'password'}
    placeholder="Enter password"
    endContent={
      <button
        type="button"
        onClick={() => setShowPassword((prev) => !prev)}
        aria-label={showPassword ? 'Hide password' : 'Show password'}
      >
        {showPassword ? <EyeOff className="h-4 w-4" /> : <Eye className="h-4 w-4" />}
      </button>
    }
  />
</InputField>;
```

## Standalone CSS

`InputField` can also be used in non-Tailwind projects via the pre-compiled `@ideasui/styles` package.

Install the standalone styles package:

```bash
pnpm add @ideasui/styles
```

Import base tokens and the input field component stylesheet:

```tsx
import '@ideasui/styles/base.css';
import '@ideasui/styles/components/input-field.css';
```

Or import all component styles in a single bundle:

```tsx
import '@ideasui/styles';
```

### BEM CSS Classes

`InputField` components expose standard BEM class names and granular slot target classes generated by the `@ideasui/theme` recipe:

- **Block / Root:** `.ideasui-input-field` (`root` slot) — Main input field root element.
- **Elements (Slots):**
  - `.ideasui-input-field__label` (`label` slot) — Label element.
  - `.ideasui-input-field__wrapper` (`wrapper` slot) — Input container wrapper (`<div>`).
  - `.ideasui-input-field__input` (`input` slot) — Native `<input>` element.
  - `.ideasui-input-field__start-content` (`startContent` slot) — Start adornment container.
  - `.ideasui-input-field__end-content` (`endContent` slot) — End adornment container.
  - `.ideasui-input-field__description` (`description` slot) — Helper description paragraph.
  - `.ideasui-input-field__error` (`errorMessage` slot) — Validation error alert paragraph.
- **BEM Modifiers:**
  - **Visual Variants:** `.ideasui-input-field__wrapper--outline`, `.ideasui-input-field__wrapper--filled`, `.ideasui-input-field__wrapper--flushed`, `.ideasui-input-field__wrapper--unstyled`, `.ideasui-input-field__wrapper--shadow`
  - **Label Variants:** `.ideasui-input-field--label-default`, `.ideasui-input-field--label-inside-fixed`, `.ideasui-input-field--label-inside-floating`, `.ideasui-input-field--label-floating`
  - **Sizes:** `.ideasui-input-field--sm`, `.ideasui-input-field--md`, `.ideasui-input-field--lg`
  - **Shadow Scale:** `.ideasui-input-field__wrapper--shadow-none`, `.ideasui-input-field__wrapper--shadow-xs`, `.ideasui-input-field__wrapper--shadow-sm`, `.ideasui-input-field__wrapper--shadow-md`, `.ideasui-input-field__wrapper--shadow-lg`, `.ideasui-input-field__wrapper--shadow-xl`
  - **States:** `.ideasui-input-field--focused`, `.ideasui-input-field--is-floating`, `.ideasui-input-field--has-start-content`, `.ideasui-input-field--invalid`, `.ideasui-input-field--disabled`

### Slot Customization

Custom CSS classes can be passed to specific inner slots using `classNames` or `slotProps`:

```tsx
<InputField
  label="Email"
  classNames={{
    root: 'custom-input-root',
    label: 'custom-label',
    wrapper: 'custom-input-wrapper',
    input: 'custom-native-input',
    description: 'custom-description',
    errorMessage: 'custom-error',
  }}
/>
```
