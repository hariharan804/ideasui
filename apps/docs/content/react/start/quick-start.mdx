## Configuration

Import the theme stylesheet into your global CSS file. If you are using Tailwind CSS v4, include `@ideasui/theme/index.css` alongside `@import 'tailwindcss'`:

```css
/* app/globals.css or src/index.css */
@import 'tailwindcss';
@import '@ideasui/theme/index.css';
```

If your project does not use Tailwind CSS, install `@ideasui/styles` for pre-compiled component stylesheets. See the [Standalone CSS](/react/docs/start/standalone-css) guide for setup details.

---

## Usage

Import components from `@ideasui/react` (or from standalone packages like `@ideasui/button`) and add them to your app:

```tsx
import { Button, ButtonGroup } from '@ideasui/react';

export default function App() {
  return (
    <div className="bg-surface flex min-h-screen items-center justify-center p-8">
      <ButtonGroup>
        <Button color="primary">Save Changes</Button>
        <Button variant="outline">Cancel</Button>
      </ButtonGroup>
    </div>
  );
}
```

---

## Framework Integration

IdeasUI works with Next.js, Vite, and other React-based frameworks.

- **Next.js**: Add `@import '@ideasui/theme/index.css';` to `app/globals.css` or import it in `app/layout.tsx`.
- **Vite**: Import `@ideasui/theme/index.css` in `src/main.tsx` or `src/index.css`.

For step-by-step instructions for specific frameworks, see the [Frameworks](/react/docs/start/frameworks) guide.
