**IdeasUI** is a React component library built with Tailwind CSS v4, React Aria primitives, and OKLCH design tokens.

It combines three core technologies:

- **Tailwind CSS v4** for flexible, utility-first styling.
- **React Aria primitives** for accessible interactions and keyboard navigation.
- **OKLCH design tokens** for consistent colors across light and dark themes.

Whether you're building an internal tool, a SaaS application, or a design system, IdeasUI provides components that are easy to customize and extend.

---

## Core Philosophy

- **Accessible by Default**: Powered by React Aria primitives for keyboard navigation, focus management, and screen reader support out of the box.
- **Tailwind v4 Native**: Integrates with Tailwind CSS v4 using CSS variables and OKLCH design tokens for light and dark theme switching.
- **Modular & Tree-Shakeable**: Use the complete `@ideasui/react` package or install standalone packages like `@ideasui/button` when you only need specific components.
- **Easy to Customize**: Uses Tailwind Variants (`tv()`), allowing you to adapt component recipes, slots, and variants without fighting default styles.

---

## Package Architecture

IdeasUI is structured as a modular monorepo:

- **`@ideasui/react`**: Main package providing access to all components.
- **`@ideasui/theme`**: OKLCH design tokens, color system, style recipes, and Tailwind v4 theme CSS.
- **`@ideasui/styles`**: Pre-compiled stylesheets for projects that do not use Tailwind CSS.
- **`@ideasui/utils`**: Shared helpers, including class merging (`cn`) and DOM utilities.
- **`@ideasui/*`**: Standalone component packages for individual components.

Individual component packages are also available when you only need specific components.
