title: Dark Mode
description: Add light and dark themes to your IdeasUI application with automatic system detection and theme switching.

IdeasUI includes built-in support for light and dark themes. The theme system uses CSS variables, so components automatically adapt when the active theme changes.

You can let the user's system preference control the theme or give them a simple light/dark toggle in your application.

---

## How Dark Mode Works

IdeasUI uses the theme variables provided by `@ideasui/theme`.

When the active theme changes, the semantic colors used by components are updated automatically. You don't need to define separate colors for every component.

For example:

```tsx
<div className="bg-surface text-content-primary">
  <h1>Welcome to IdeasUI</h1>
  <p>Your application works in both light and dark mode.</p>
</div>
```

The same classes work in both themes.

---

## Using the Theme Provider

For applications that need runtime theme switching, use `ThemeProvider` from `@ideasui/theme`:

```tsx
import { ThemeProvider } from '@ideasui/theme';

export function Providers({ children }: { children: React.ReactNode }) {
  return <ThemeProvider defaultTheme="system">{children}</ThemeProvider>;
}
```

With `defaultTheme="system"`, IdeasUI follows the user's operating-system preference.

You can also start with a specific theme:

```tsx
<ThemeProvider defaultTheme="light">{children}</ThemeProvider>
```

or:

```tsx
<ThemeProvider defaultTheme="dark">{children}</ThemeProvider>
```

---

## Adding a Theme Toggle

If your application allows users to switch themes, connect your theme toggle to the theme provider.

Keep the toggle focused on changing the theme rather than manually changing colors throughout the application.

For example:

```tsx
import { useTheme } from '@ideasui/theme';

export function ThemeToggle() {
  const { theme, setTheme } = useTheme();

  return (
    <button onClick={() => setTheme(theme === 'dark' ? 'light' : 'dark')}>
      {theme === 'dark' ? 'Light mode' : 'Dark mode'}
    </button>
  );
}
```

The exact toggle UI is up to your application. IdeasUI handles the theme state and CSS variables underneath.

---

## System Theme

Use `system` when you want the application to follow the user's operating-system preference:

```tsx
<ThemeProvider defaultTheme="system">{children}</ThemeProvider>
```

This is a good default for applications where users should not have to choose a theme manually.

---

## Preventing Theme Flicker

When using SSR frameworks such as Next.js, the server-rendered page may initially use a different theme from the user's saved preference.

Add `ThemeScript` to the document head to apply the correct theme before the page is rendered:

```tsx
import { ThemeScript } from '@ideasui/theme';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en" suppressHydrationWarning>
      <head>
        <ThemeScript />
      </head>
      <body>{children}</body>
    </html>
  );
}
```

This helps avoid a visible flash when the application loads.

---

## Using Theme Tokens

Prefer IdeasUI's semantic tokens instead of hard-coding light and dark colors.

```tsx
<div className="bg-surface text-content-primary">
  <div className="bg-surface-subtle">
    <span className="text-content-secondary">Theme-aware content</span>
  </div>
</div>
```

Because these values come from the theme, the same component can be used in both light and dark mode.
