Set up IdeasUI in your preferred React framework.

---

## Next.js

### 1. Create a Next.js project

Create a new application using `create-next-app`:

```bash
npx create-next-app@latest
```

Select your preferred configuration options (we recommend TypeScript, Tailwind CSS, and App Router):

```bash
✔ What is your project named? … my-app
✔ Would you like to use TypeScript? … Yes
✔ Would you like to use ESLint? … Yes
✔ Would you like to use Tailwind CSS? … Yes
✔ Would you like to use `src/` directory? … Yes
✔ Would you like to use App Router? … Yes
✔ Would you like to customize the default import alias (@/*)? … No
```

### 2. Install IdeasUI

Install `@ideasui/react` and `@ideasui/theme`:

<InstallTabs pkg="@ideasui/react @ideasui/theme" defaultMode="core" />

### 3. Add the stylesheet

Import Tailwind CSS and `@ideasui/theme/index.css` in `app/globals.css`:

```css
/* app/globals.css */
@import 'tailwindcss';
@import '@ideasui/theme/index.css';
```

Or import the CSS directly in your root layout:

```tsx
// app/layout.tsx
import '@ideasui/theme/index.css';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en" suppressHydrationWarning>
      <body>{children}</body>
    </html>
  );
}
```

### 4. Add a component

Use IdeasUI components in your application pages:

```tsx
// app/page.tsx
import { Button, ButtonGroup } from '@ideasui/react';

export default function HomePage() {
  return (
    <main className="bg-surface flex min-h-screen items-center justify-center p-8">
      <ButtonGroup>
        <Button color="primary">Save Changes</Button>
        <Button variant="outline">Cancel</Button>
      </ButtonGroup>
    </main>
  );
}
```

## Vite

### 1. Create a Vite project

Create a new React and TypeScript app using Vite:

```bash
npm create vite@latest my-app -- --template react-ts
```

### 2. Install IdeasUI

Install `@ideasui/react` and `@ideasui/theme`:

<InstallTabs pkg="@ideasui/react @ideasui/theme" defaultMode="core" />

### 3. Add the stylesheet

Import `@ideasui/theme/index.css` in `src/main.tsx`:

```tsx
// src/main.tsx
import React from 'react';
import ReactDOM from 'react-dom/client';
import '@ideasui/theme/index.css';
import App from './App';

ReactDOM.createRoot(document.getElementById('root')!).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>,
);
```

### 4. Add a component

Add an IdeasUI component to your app:

```tsx
// src/App.tsx
import { Button } from '@ideasui/react';

export default function App() {
  return (
    <main className="bg-surface flex min-h-screen items-center justify-center p-8">
      <Button color="primary">Get Started</Button>
    </main>
  );
}
```

## Remix / React Router

### 1. Create a project

Create a new Remix or React Router application:

```bash
npx create-remix@latest
```

### 2. Install IdeasUI

Install `@ideasui/react` and `@ideasui/theme`:

<InstallTabs pkg="@ideasui/react @ideasui/theme" defaultMode="core" />

### 3. Add the stylesheet

Import `@ideasui/theme/index.css` in `app/root.tsx`:

```tsx
// app/root.tsx
import { Links, Meta, Outlet, Scripts } from '@remix-run/react';
import '@ideasui/theme/index.css';

export default function App() {
  return (
    <html lang="en">
      <head>
        <Meta />
        <Links />
      </head>
      <body className="bg-surface text-content-primary">
        <Outlet />
        <Scripts />
      </body>
    </html>
  );
}
```

### 4. Add a component

Add an IdeasUI component to your route:

```tsx
// app/routes/_index.tsx
import { Button } from '@ideasui/react';

export default function Index() {
  return (
    <main className="bg-surface flex min-h-screen items-center justify-center p-8">
      <Button color="primary">Get Started</Button>
    </main>
  );
}
```
