If your project does not use Tailwind CSS, you can use **`@ideasui/styles`** to get pre-compiled styles for IdeasUI components.

This is useful when you want to use IdeasUI without adding Tailwind CSS to your existing build setup.

---

## Installation

Install the `@ideasui/styles` package:

<InstallTabs pkg="@ideasui/styles" defaultMode="component" />

## Usage

### All-in-One CSS

For most projects, import the base styles and the complete IdeasUI stylesheet once in your application entry point:

```tsx
// src/main.tsx
import '@ideasui/styles/base.css';
import '@ideasui/styles/styles.css';
```

You can then use IdeasUI components normally:

```tsx
import { Button } from '@ideasui/react';

export default function App() {
  return <Button color="primary">Click Me</Button>;
}
```

---

### Component-Wise CSS

If you only use a few components, you can import their styles individually.

Import the base styles once:

```tsx
import '@ideasui/styles/base.css';
```

Then import the styles for the components you use:

```tsx
import '@ideasui/styles/components/button.css';
```

Use the component normally:

```tsx
import { Button } from '@ideasui/react';

export default function App() {
  return <Button color="primary">Click Me</Button>;
}
```

This keeps your CSS bundle smaller when you only use a few components.

---

## Stylesheet Reference

| File                                         | Description                                      |
| -------------------------------------------- | ------------------------------------------------ |
| `@ideasui/styles/base.css`                   | Base resets, theme variables, and shared styles. |
| `@ideasui/styles/styles.css`                 | Pre-compiled styles for all IdeasUI components.  |
| `@ideasui/styles/components/[component].css` | Pre-compiled styles for an individual component. |

---

## When to Use Standalone CSS

Use `@ideasui/styles` when:

- Your project does not use Tailwind CSS.
- You don't want to add Tailwind CSS to your build pipeline.
- You prefer pre-compiled CSS.
- You are using IdeasUI alongside another component library and only need specific IdeasUI components.
- You want to import styles for only the components you use.

If your project already uses Tailwind CSS v4, use the regular **[Theming](/react/docs/start/theming)** setup instead.
