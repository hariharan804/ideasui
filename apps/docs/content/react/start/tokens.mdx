## What are Design Tokens?

IdeasUI uses design tokens to keep colors, spacing, typography, radius, and other visual values consistent across your application.

Instead of hardcoding visual values, use IdeasUI's semantic Tailwind utilities. These tokens adapt to the active theme, making your UI easier to customize and maintain.

---

## How to Use Tokens

Prefer using semantic tokens (e.g., `bg-surface`, `text-content-primary`) rather than absolute color values. Semantic tokens adapt automatically to light and dark themes.

---

### Colors: Surface & Layout

Surface colors form the foundational backgrounds of your layout.

- **`bg-background`**: The primary page background (`<body>`).
- **`bg-surface`**: Main container background for cards and layout components.
- **`bg-surface-subtle`**: Slightly softer surface background for secondary sections.
- **`bg-surface-muted`**: Subtle surface background for inset content, code blocks, or grouped items.
- **`bg-surface-strong`**: Emphasized surface background for elevated panels or active states.
- **`bg-surface-overlay`**: Elevated background for overlay components like dialogs, popovers, and menus.
- **`bg-surface-inverse`**: High-contrast surface background opposing the current theme.

---

### Colors: Content & Text

Content tokens style text, icons, and inline elements on surfaces.

- **`text-content-primary`**: High contrast for primary text, headings, and key icons.
- **`text-content-secondary`**: Medium contrast for secondary text and subtitles.
- **`text-content-tertiary`**: Lower contrast for captions, timestamps, and metadata.
- **`text-content-muted`**: Very low contrast for placeholder text and disabled hints.
- **`text-content-inverse`**: Inverted text color for placement on dark or inverse surfaces.

---

### Colors: Semantic Actions

Semantic colors convey purpose and status across interactive components like Buttons, Badges, and Alerts.

Every semantic color supports subtle and muted variants (e.g., `primary`, `primary-subtle`, `primary-muted`).

- **`primary` / `secondary` / `tertiary`**: Brand and hierarchy colors for key actions.
- **`neutral`**: Neutral surfaces, subtle borders, and structural elements.
- **`success`**: Positive outcomes and status indicators.
- **`warning`**: Warnings and caution indicators.
- **`danger`**: Destructive actions and error states.
- **`info`**: Informational messaging and feature highlights.

**Usage Examples:**

- `bg-primary text-on-primary` for high-emphasis buttons.
- `bg-danger-subtle text-on-danger-subtle` for low-emphasis error badges.

---

### Spacing & Layout

IdeasUI uses a consistent spacing scale based on a 4px base unit.

- **`gap-2` / `p-2` (8px)**: Tight spacing between closely related elements.
- **`gap-4` / `p-4` (16px)**: Standard spacing for card padding and form fields.
- **`gap-8` / `mb-8` (32px)**: Larger spacing between sections and major layout elements.

---

### Typography

Our typography scale ensures proper `font-size` and `line-height` ratios across display and body text.

- **`text-xs` / `text-sm`**: Metadata, helper text, and compact UI components (badges, tooltips).
- **`text-base`**: Standard font size for primary UI content and body text.
- **`text-lg` / `text-xl`**: Card titles, section headers, and emphasized labels.
- **`text-2xl` to `text-5xl`**: Page headers, display titles, and hero titles.

---

### Radius (Corners)

Corner radiuses define component border curvature and visual shape.

- **`rounded-sm` / `rounded`**: Subtle corner radius for small UI controls.
- **`rounded-md` / `rounded-lg`**: Standard border radius for buttons, inputs, and cards.
- **`rounded-xl` / `rounded-2xl`**: Larger radius for elevated cards, dialogs, and modals.
- **`rounded-full`**: Pill shapes, badges, and circular avatars.

---

### Shadows & Effects

Shadows and blurs establish visual depth and z-index hierarchy.

- **`shadow-sm`**: Subtle elevation for interactive controls and subtle cards.
- **`shadow-md`**: Standard elevation for cards and floating elements.
- **`shadow-lg` / `shadow-xl`**: Deep elevation for popovers, dropdowns, and modals.
- **`backdrop-blur-md`**: Glassmorphism backdrop blur using IdeasUI blur tokens (`--ideasui-blur-md`).
