# @ideasui/docs

The official documentation website for **IdeasUI** — built with **Next.js 16**, **Fumadocs**, and **Tailwind CSS v4**.

## 🚀 Getting Started

From the root of the IdeasUI monorepo:

```bash
# Install dependencies
pnpm install

# Start the docs development server
pnpm run dev:docs
```

Or from within `apps/docs`:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the documentation site.

## 🛠️ Features

- **Fumadocs Engine**: Fast MDX rendering with search and interactive component demos.
- **Dynamic Theme Customizer**: Live preview modal for color modes, primary accent colors, and corner radius.
- **Showcase Integration**: Component code examples directly linked to source files.
