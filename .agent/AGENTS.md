# IdeasUI — AI Agent Guide

IdeasUI is a **React component library monorepo** built with TypeScript, Tailwind CSS v4, Tailwind Variants (tv), React Aria Components, and an OKLCH color system. It targets WCAG 2.1 AA accessibility by default.

---

## 📦 Package Map

```
packages/
├── components/
│   └── button/               → @ideasui/button        (only component so far)
├── core/
│   ├── theme/                → @ideasui/theme          (design tokens, recipes, ThemeProvider)
│   ├── styles/               → @ideasui/styles         (base/global CSS)
│   └── react/                → @ideasui/react          (master barrel bundle)
└── utils/                    → @ideasui/utils          (cn, getAccessibleName, mergePropsWithContext)

apps/
├── playground/               → Next.js 15 dev sandbox
├── storybook/                → Storybook 10 component docs
└── docs/                     → Next.js docs site
```

### Allowed Dependency Direction

```
components → theme, utils, hooks
hooks      → utils
utils      → (nothing)
theme      → utils
```

**Never** import one component from another component's `src/`.

## 🏗️ Component Anatomy

Every component lives at `packages/components/<name>/src/` and follows this structure:

```
button/
├── src/
│   ├── button.tsx          ← Main component (forwardRef, displayName)
│   ├── button.types.ts     ← All TypeScript types with JSDoc
│   ├── button-group.tsx    ← Related sub-components (if needed)
│   └── index.ts            ← Barrel export (public API only)
├── __tests__/
│   └── button.test.tsx     ← Vitest + RTL + vitest-axe
├── stories/
│   └── button.stories.tsx  ← Storybook stories
├── package.json
├── tsconfig.json
└── tsup.config.ts
```

> **Canonical reference:** See `packages/components/button/src/button.tsx` for the gold standard implementation pattern (Context, slots, forwardRef, displayName, react-aria integration).

## 🎨 Styling Pattern

All styles use **Tailwind Variants (`tv()`)** via recipes from `@ideasui/theme/recipes`. Use `cn()` from `@ideasui/utils` to merge class names.

```tsx
import { button } from '@ideasui/theme/recipes'; // tv() recipe
import { cn } from '@ideasui/utils'; // class merger

const styles = button({ variant, size, color, radius });
<button className={styles.base({ className })} />;
```

Recipes live at: `packages/core/theme/src/recipes/`

Colors are OKLCH-based CSS custom properties (`--ideasui-color-primary`, `--ideasui-color-surface`, etc.), generated by the theme plugin.

## ♿ Accessibility

- Use **React Aria Components** as primitive base (`react-aria-components`)
- Semantic HTML first (`<button>` for actions, `<a>` for links)
- All interactive components must pass `vitest-axe` with zero violations
- `data-slot="*"` attributes on all rendered DOM slots for targeting
- Icon-only triggers **must** receive `aria-label` enforced at TypeScript type level

## 📋 Naming Conventions (Quick Reference)

| Context         | Convention              | Example                 |
| --------------- | ----------------------- | ----------------------- |
| File name       | kebab-case              | `input-field.tsx`       |
| Folder name     | kebab-case              | `packages/input-field/` |
| Package name    | kebab-case              | `@ideasui/input-field`  |
| Component name  | PascalCase              | `InputField`            |
| `displayName`   | `IdeasUI.ComponentName` | `IdeasUI.Button`        |
| Variable/fn     | camelCase               | `buttonVariants`        |
| Type/Interface  | PascalCase              | `ButtonProps`           |
| Constant        | SCREAMING_SNAKE_CASE    | `MAX_SIZE`              |
| CSS class (BEM) | kebab-case              | `btn`, `btn--solid`     |

Full details → `rules/naming-conventions.md`
